# 『統計のための数理サプリメント』R コード

神谷之康『統計のための数理サプリメント ── 原理から組み立てる現代のデータ分析』（サイエンス社）の本文に出てくる R の例と，本文の主な計算値を，章ごとのスクリプトにまとめたものです。

## 使い方

1. このページ右上の「Code」→「Download ZIP」で一式を取り，展開します。
2. R で，展開したフォルダの中の `R/` フォルダを作業ディレクトリにします。
   RStudio なら，`R/` の中のスクリプトを開いて，メニューの
   Session → Set Working Directory → To Source File Location を選びます。
3. スクリプトを走らせます。

```r
source("ch01_model_ladder.R")
```

ターミナルからなら `cd R` のあと `Rscript ch01_model_ladder.R` です（図は `Rplots.pdf` というファイルに出ます）。

**R は 4.2 以降を使ってください。** スクリプトの文字コードは UTF-8 です。Windows の R 4.1 以前では日本語が化けることがあり，日本語の変数名を使う部分（第2章のデザイン行列）は飛ばします。

乱数を使う例は，種（`set.seed()`）を固定してあるので，誰が走らせても同じ数値になります。R 4.6.1（macOS）と BayesFactor 0.9.12-4.8 で，本文の出力と一致することを確かめました。R の表示が英語のときは，メッセージの行（「2 個の観測値が欠損のため…」など）だけ英語になります。

## 中身（`R/`）

| ファイル | 章 | 内容 |
|---|---|---|
| `data_students24.R` | 第1・2・4・5・9章 | 本書で何度も使う24人の成績データを作る（乱数の種を固定） |
| `ch01_model_ladder.R` | 第1章 モデルの育て方 | 1つの数から変数を足していき，RMSE の変化を見る |
| `ch02_t_test_anova_glm.R` | 第2章 モデルの着せ替え | t検定と `lm()`，分散分析，ロジスティック回帰，正規方程式，デザイン行列 |
| `ch03_formulas.R` | 第3章 公式の導き方 | 二乗誤差を最小にする値，内積から相関係数 |
| `ch04_distributions.R` | 第4章 分布という語彙 | 数値積分，モンテカルロ法，z スコア，主成分分析 |
| `ch05_inference.R` | 第5章 推測のしくみ | 標準誤差・信頼区間・検定・効果量・多重比較などの計算値（第5章は本文に R の枠が無いので，地の文の値を確かめる） |
| `ch06_bayes.R` | 第6章 ベイズ統計の数理 | 信用区間，周辺尤度とベイズファクター，BIC（コイン投げ） |
| `ch09_reading_output.R` | 第9章 あなたの出力を読む | `summary()` の読み方，信頼区間と予測区間，診断プロット，ベイズファクター |
| `appendix_r_basics.R` | 付録 R コードの文法 | 付録の例のうち，データ（NHANES）が無くても走るもの |

`ch09_reading_output.R` の最後の部分だけ，パッケージ BayesFactor を使います（`install.packages("BayesFactor")`）。入っていなければ，その部分は飛ばします。

## 図を描くコード（`figures/`）

本の図のうち，データから描く図のコード（R と Python）を `figures/` に置いています。使い方は `figures/README.md` を見てください。本と同じ絵が描けますが，フォントや細部は環境によって変わります。
