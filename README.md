# 『統計のための数理サプリメント』R コード

神谷之康『統計のための数理サプリメント ── 原理から組み立てる現代のデータ分析』（サイエンス社）の本文に出てくる R の例を，章ごとにまとめたものです。本文の数値は，ここにあるスクリプトを走らせると再現できます。

## 使い方

R（4.x）で，`R/` フォルダを作業ディレクトリにしてから走らせます。

```r
setwd("R")              # このリポジトリの R/ フォルダ
source("ch01_model_ladder.R")
```

ターミナルからなら `cd R` のあと `Rscript ch01_model_ladder.R` です。

## 中身

| ファイル | 章 | 内容 |
|---|---|---|
| `data_students24.R` | 第1・2・9章 | 本書で何度も使う24人の成績データを作る（乱数の種を固定） |
| `ch01_model_ladder.R` | 第1章 モデルの育て方 | 1つの数から変数を足していき，RMSE の変化を見る |
| `ch02_t_test_anova_glm.R` | 第2章 モデルの着せ替え | t検定と `lm()`，分散分析，ロジスティック回帰，デザイン行列 |
| `ch03_formulas.R` | 第3章 公式の導き方 | 二乗誤差を最小にする値，内積から相関係数 |
| `ch04_distributions.R` | 第4章 分布という語彙 | 数値積分，モンテカルロ法，主成分分析 |
| `ch06_bayes.R` | 第6章 ベイズ統計の数理 | 周辺尤度とベイズファクター（コイン投げ） |
| `ch09_reading_output.R` | 第9章 あなたの出力を読む | `summary()` の読み方，信頼区間と予測区間，診断プロット，ベイズファクター |
| `appendix_r_basics.R` | 付録 R コードの文法 | 付録の例の確かめ |

`ch09_reading_output.R` の最後の部分だけ，パッケージ BayesFactor を使います（`install.packages("BayesFactor")`）。入っていなければ，その部分は飛ばします。
